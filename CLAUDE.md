# CLAUDE.md — правила работы с этим репозиторием

## Журнал багов (обязательно)

Когда исправляешь **баг** (не рефакторинг и не новую фичу), добавляй запись в
[`FIXED_BUGS_HISTORY.md`](FIXED_BUGS_HISTORY.md):

- формат — по шаблону в шапке файла: **Симптом → Причина → Фикс → Проверка**;
- фиксируй **настоящую причину** в коде/архитектуре, а не симптом и не «маскировку»;
- новые записи — **сверху**; указывай дату, коммит и серьёзность;
- по возможности — регрессионный тест, падающий без фикса.

Добавляй запись в тот же коммит, что и сам фикс.

## Синхронизация документации

Обновляй `docs/`, когда меняешь код, который они описывают (в репозиторий заходят новые
разработчики — доки не должны отставать от кода).

## Тесты

`pytest` из корня (нужен Python 3.12; см. `requirements-dev.txt`). Прогоняй сюиту перед
коммитом фикса; для критичных фиксов добавляй тест, который **падает без фикса** (проверяй
мутацией).
