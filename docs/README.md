## Быстрый словарь

- **Исполнитель** — отдельный процесс: `api` (FastAPI), `llm_worker`, `summarizer`.
- **Горячий путь** — синхронная часть, где пользователь ждёт ответ (api + доставка токенов).
- **Холодное хранилище** — Postgres, source of truth, живёт вечно.
- **Горячая проекция** — данные в Redis с TTL: контекст, резюме, ленты генераций.
- **`conversation_id`** — ключ маршрутизации: по нему бьются каналы, ленты, замки.
